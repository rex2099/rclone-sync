Privacy Policy

Rclone External Sync is a private, personal-use application for synchronizing files between a local external hard drive and Google Drive.

Data Access and Use

The application accesses Google Drive files, folders, and associated metadata solely to perform authorized file synchronization, backup, and file management.

Data Storage and Protection

Synchronized files and OAuth credentials are stored locally on the owner's computer or external storage devices.

The application does not operate a separate server for collecting Google user data.

Data Sharing

Google user data is not sold, shared with third parties, used for advertising, or used to train artificial intelligence models.

Data Retention and Deletion

The owner controls the retention and deletion of synchronized files and locally stored credentials. Google account access can be revoked at any time through Google Account security settings.

Google API Compliance

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

For privacy-related inquiries, contact the application owner through the GitHub repository.
